Live2D ImGuui Overlay(Android游戏内嵌Live2D助手)

在安卓游戏/应用中叠加ImGuui控制面板+Live2D动态模型的注入框架，基于CoisiniLuaR开源项目(https://b23.tv/mTJBrON)(Debug小白)二次开发，针对动画表现、交互手感与GL状态安全做了大量优化.

✨   核心特性

·ImGuui界面+Live2D模型无缝叠加：多比注入eglSwapBuffers，每帧渲染游戏画面同时绘制Live2D模型窗口
·完整GL状态保护：渲染Live2D前快照程序/VAO/FBO/视口/纹理/混合/深度等状态，渲染后原样恢复，不污染游戏渲染管线
·Live2D离屏渲染：模型渲染到2048×2048 FBO，再作为纹理显示在ImGui预览窗口中
• 触摸点视线跟随：按下屏幕任意位置，人物视线平滑朝向触摸点方向；坐标以模型显示区域中心为基准归一化，无论人物窗口拖到屏幕左/中/右，方向感都正确
• 头/眼分离缓动：头部与眼球以不同速度平滑追踪（头部慢、眼球快），配合指数平滑，转动自然不生硬；无输入时缓慢回正并做防抖归零
·自动眨眼：随机间隔(2~5s)+sin曲线"快闭慢开"
·呼吸起伏：身体轻微起伏(ParamBodyAngleZ/ParamBreath)
·模拟说话：嘴巴随机开合(ParamMouthOpenY/ParamMouthForm)
• 互斥交互：短按（≤0.35s）播放轻击体运动，长按（>0.35s）模拟说话，二者通过按住时长阈值严格互斥，不会冲突
• 控制面板实时调参：头部/眼球/回正速度、头部幅度（±10°~80°）、模型缩放、各扩展开关均可即时调节
• 一键触发：播放怠速运动 / 轻击体运动 / 随机表情

🛠    技术栈

模块	技术
注入/钩多臂直列钩
挂钩点eglSwapBuffers、libinput.so：：initializeMotionEvent、ANativeWindow_getWidth/Height
UI尊敬的ImGuui(含Android/OpenGL3后端)
Live2D Live2D Cubism SDK(Hiyori示例模型）
渲染OpenGL ES2/3，固定基地运营商离屏+纹理叠加

🚀 使用说明

1.将项目编译为.so注入目标游戏(libil2cpp.so场景，一般配合模块加载器使用）
2.游戏内呼出ImGuui菜单，打开"Live2D控制”面板
3.在"Live2D预览"窗口中查看模型，可与人物交互

操作指南

操作	效果
手指在屏幕任意位置滑动	人物视线跟随触摸点（上下/左右）
短按模型区域（≤0.35s）	播放轻击体运动
长按模型区域（>0.35s）	模拟说话
拖动窗口标题栏	移动模型窗口到任意位置，视线方向仍正确

视线跟随模式

• 关闭：人物保持默认状态
• 触摸点跟随（默认）：按下时跟随手指，松开回正

⚙️     可调参数

• 头部速度 / 眼球速度（缓动速度分离）
• 回正速度
• 头部幅度（角度增益）
• 模型缩放
• 自动眨眼 / 呼吸起伏 / 按住说话 开关

📦 更新亮点（近期迭代）

• 修复触摸 X 轴响应：原先以屏幕中心为原点归一化坐标，人物在屏幕两侧时左右几乎无响应；改为以模型显示区域中心为基准计算相对偏移，人物在任何位置都能正确跟随左右视线
• 短按/长按互斥：引入 0.35s 长按阈值，消除"按住说话结束后误触发点击"的冲突
• 精简 & 模块化：剥离与 Live2D 无关的业务逻辑（ESP、菜单、内存读写等），保留纯净的 Live2D 集成链路，便于二次开发
